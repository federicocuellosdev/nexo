> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir la sección pública de la maqueta Nexo 3.0 (home, catálogo, fichas de plan y producto, popup de alta y "revisá tu mail") y el handoff por URL hacia el portal.

**Architecture:** SPA Vite + React 19 con React Router 7 en modo librería. Dependencia estricta `pages → layouts/features → ui`; `lib/` y `mock/` son hojas. Los primitivos de `src/ui/`, `src/styles/`, `src/lib/cn.ts`, `src/lib/formato.ts` y `src/mock/planes.ts` se escriben acá y el repo `nexo-3.0-portal` los COPIA 1:1 (decisión del spec §2: duplicación en vez de paquete compartido), así que sus nombres y firmas son contrato entre los dos repos.

**Tech Stack:** Vite 7.3.6 · React 19.2.8 · TypeScript 5.9.3 (strict) · Tailwind v4.3.3 vía `@tailwindcss/vite` con `@theme` · React Router 7.18.3 · `@radix-ui/react-dialog` 1.1.23 · `@radix-ui/react-tabs` 1.1.21 · lucide-react 1.42.0 · Vitest 4.1.11 + Testing Library 16.3.3 + jsdom 27.4.0 · Playwright 1.63.0. Sin Framer Motion.

**Spec:** `docs/superpowers/specs/2026-09-07-nexo-3.0-maqueta-design.md` (idéntico en ambos repos). Contexto de producto: `docs/CONTEXTO.md`. Reglas del repo: `AGENTS.md`.

## Global Constraints

- Rama de trabajo: `nexo-3.0`. Nunca merge desde/hacia `main` o `staging` (AGENTS.md).
- Código nuevo desde cero: NO se importa código de Nexo 2.0. SÍ se portan los DATOS de planes y la identidad visual.
- Gestor de paquetes: **npm** (no hay pnpm en la máquina). Node 26, npm 11.
- TypeScript estricto, sin `any`. Componentes funcionales, **exports nombrados** (nunca `export default`).
- Conventional commits en español, **sin ninguna atribución de IA** (regla dura del usuario). Un commit = una unidad de trabajo revisable.
- **El repo tiene un hook `pre-commit` (GGA) que revisa los `*.ts`/`*.tsx` del commit contra `AGENTS.md`. Tarda ~30–60 s por commit: es normal, no lo canceles y no uses `--no-verify`.**
- Alias de importación: `@/` → `src/`. Usalo siempre (hace trivial el copiado al portal).
- Regla de dependencia: `pages → layouts/features → ui`. `lib/` y `mock/` son hojas. Importar `mock/` desde `ui/` está PROHIBIDO. `lib/` puede importar TIPOS de `mock/` con `import type` (se borra en compilación), nunca valores.
- Mobile-first: cada layout se define primero para 390 px y después se agregan `md:` / `lg:`.
- Dirección visual (spec §7): fondo de app `#f6f5fb`, superficies blancas, radios 16 / 10 / pill, degradado de marca SOLO en el CTA primario y acentos, chips de estado, listas con icono en círculo, DM Serif Display solo en display.
- Flags `pendiente: true` (spec §8) se renderizan SIEMPRE con un chip "a confirmar" tono `warn`. Nunca se ocultan.
- Motion: transiciones 200–300 ms, entradas con `@starting-style` (variante `starting:` de Tailwind), y `motion-reduce:` para anular desplazamientos dejando solo opacidad.
- Accesibilidad: foco visible, contraste AA, `<label>` reales, `aria-current` en navegación.
- Todo texto de fixture es claramente demo; nada se presenta como dato real del cliente.

```ts
/**
 * Concatena clases de Tailwind descartando los condicionales falsos.
 * No resuelve conflictos (no es `tailwind-merge`): el orden lo decide quien
 * llama, y las props `className` van SIEMPRE al final en cada primitivo.

export type ClaseCondicional = string | false | null | undefined;
```

```ts
/**
 * Formateo de miles a mano. `toLocaleString` puede dar distinto en Node y en el
 * browser, y eso rompería tanto los tests como la coincidencia del render.
 */
export function formatearMiles(n: number): string {
  const entero = Math.trunc(Math.abs(n)).toString();
  const conPuntos = entero.replace(/\B(?=(\d{3})+(?!\d))/g, '.');
  return n < 0 ? `-${conPuntos}` : conPuntos;
}

export function formatearPrecio(n: number): string {
  return `$${formatearMiles(n)}`;
}

/**
 * Parte el monto para el patrón de `Money`: entero grande y decimales en
 * superíndice (spec §7).
 */
export function partesMoneda(n: number): { entero: string; decimales: string } {
  const centavos = Math.round(Math.abs(n) * 100);
  const entero = Math.trunc(centavos / 100);
  const decimales = (centavos % 100).toString().padStart(2, '0');
  return { entero: `${n < 0 ? '-' : ''}${formatearMiles(entero)}`, decimales };
}

/**
 * Precio de entrada ("desde $X/mes"). Se deriva de la lista en vez de
 * hardcodearse: en Nexo 2.0 quedó un precio viejo pegado en seis lugares del
 * sitio. Recibe la lista por parámetro para que `lib/` siga siendo una hoja y
 * no importe `mock/`.
 */
export function precioDesde(items: ReadonlyArray<{ precio: number }>): number {
  const primero = items[0];
  if (primero === undefined) throw new Error('precioDesde necesita al menos un ítem');
  return items.reduce((minimo, item) => (item.precio < minimo ? item.precio : minimo), primero.precio);
}
```

```tsx
import type { ButtonHTMLAttributes, ReactNode } from 'react';
import { cn } from '@/lib/cn';

export type VarianteBoton = 'primario' | 'secundario' | 'fantasma' | 'peligro';
export type TamanoBoton = 'sm' | 'md' | 'lg';

export interface OpcionesBoton {
  variante?: VarianteBoton;
  tamano?: TamanoBoton;
  ancho?: 'auto' | 'full';
  className?: string;
}

export interface ButtonProps extends ButtonHTMLAttributes<HTMLButtonElement>, OpcionesBoton {
  children: ReactNode;
}

const BASE = [
  'inline-flex items-center justify-center gap-2 rounded-pill font-medium whitespace-nowrap',
  'transition-[background-color,box-shadow,color,transform] duration-200 ease-out-expo',
  'motion-safe:active:scale-[0.98]',
  'disabled:pointer-events-none disabled:opacity-50',
  'focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-marca-500',
].join(' ');

const VARIANTES: Record<VarianteBoton, string> = {
  // El degradado de marca queda reservado a este CTA (spec §7).
  primario: 'bg-brand text-white shadow-card hover:shadow-elevada',
  secundario: 'bg-white text-ink-900 border border-ink-200 hover:border-ink-300 hover:bg-ink-50',
  fantasma: 'bg-transparent text-marca-600 hover:bg-marca-50',
  peligro: 'bg-white text-danger-700 border border-danger-500/30 hover:bg-danger-50',
};

const TAMANOS: Record<TamanoBoton, string> = {
  sm: 'h-9 px-4 text-sm',
  md: 'h-11 px-5 text-base',
  lg: 'h-13 px-6 text-base',
};

/**
 * Las mismas clases del botón, sin el `<button>`. La usan los `<Link>` y `<a>`
 * que tienen que verse como CTA: navegar con un `<button onClick>` rompe
 * "abrir en pestaña nueva" y el foco del teclado.
 */
export function clasesBoton({
  variante = 'primario',
  tamano = 'md',
  ancho = 'auto',
  className,
}: OpcionesBoton = {}): string {
  return cn(BASE, VARIANTES[variante], TAMANOS[tamano], ancho === 'full' && 'w-full', className);
}

export function Button({
  variante = 'primario',
  tamano = 'md',
  ancho = 'auto',
  className,
  type = 'button',
  children,
  ...resto
}: ButtonProps) {
  return (
    <button type={type} className={clasesBoton({ variante, tamano, ancho, className })} {...resto}>
      {children}
    </button>
  );
}
```

```tsx
import { partesMoneda } from '@/lib/formato';
import { cn } from '@/lib/cn';

export interface MoneyProps {
  monto: number;
  /** Texto que acompaña al monto: "por mes", "único pago". */
  periodo?: string;
  tamano?: 'md' | 'lg';
  className?: string;
}

/**
 * Patrón de precio de aplicación (spec §7): entero grande y centavos en
 * superíndice. Las partes visuales quedan ocultas al lector de pantalla y se
 * expone una sola frase legible, que si no se escucharía "veinte punto cero
 * cero cero cero cero".
 */
export function Money({ monto, periodo, tamano = 'md', className }: MoneyProps) {
  const { entero, decimales } = partesMoneda(monto);
  const accesible = `$${entero},${decimales}${periodo ? ` ${periodo}` : ''}`;

  return (
    <span
      className={cn(
        'inline-flex items-baseline font-semibold text-ink-950',
        tamano === 'lg' ? 'text-2xl' : 'text-xl',
        className,
      )}
    >
      <span aria-hidden="true" className="mr-0.5">
        $
      </span>
      <span aria-hidden="true">{entero}</span>
      <sup aria-hidden="true" className="ml-0.5 text-[0.5em] font-semibold">
        {decimales}
      </sup>
      {periodo ? (
        <span aria-hidden="true" className="ml-1.5 text-sm font-normal text-ink-500">
          {periodo}
        </span>
      ) : null}
      <span className="sr-only">{accesible}</span>
    </span>
  );
}
```

```tsx
import type { ReactNode } from 'react';
import * as RadixTabs from '@radix-ui/react-tabs';

export interface ItemTab {
  valor: string;
  label: string;
}

export interface TabsProps {
  valor: string;
  onCambio: (valor: string) => void;
  items: ItemTab[];
  /** Nombre accesible de la lista de pestañas. */
  etiqueta: string;
  children: ReactNode;
}

export function Tabs({ valor, onCambio, items, etiqueta, children }: TabsProps) {
  return (
    <RadixTabs.Root value={valor} onValueChange={onCambio}>
      <RadixTabs.List
        aria-label={etiqueta}
        className="mb-5 inline-flex gap-1 rounded-pill bg-ink-100 p-1"
      >
        {items.map((item) => (
          <RadixTabs.Trigger
            key={item.valor}
            value={item.valor}
            className={[
              'rounded-pill px-4 py-2 text-sm font-medium text-ink-600',
              'transition-colors duration-200 ease-out-quart',
              'data-[state=active]:bg-white data-[state=active]:text-ink-950 data-[state=active]:shadow-suave',
              'focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-marca-500',
            ].join(' ')}
          >
            {item.label}
          </RadixTabs.Trigger>
        ))}
      </RadixTabs.List>
      {children}
    </RadixTabs.Root>
  );
}

export function TabPanel({ valor, children }: { valor: string; children: ReactNode }) {
  return (
    <RadixTabs.Content value={valor} className="focus-visible:outline-none">
      {children}
    </RadixTabs.Content>
  );
}
```

```tsx
import { Link } from 'react-router';
import { Check } from 'lucide-react';
import type { Plan } from '@/mock/planes';
import { Card } from '@/ui/Card';
import { Badge } from '@/ui/Badge';
import { Chip } from '@/ui/Chip';
import { Icon } from '@/ui/Icon';
import { Money } from '@/ui/Money';
import { Button, clasesBoton } from '@/ui/Button';

export interface PlanCardProps {
  plan: Plan;
  destacado?: boolean;
  activo?: boolean;
  hrefDetalle?: string;
  onCta?: (plan: Plan) => void;
  etiquetaCta?: string;
}

const MAXIMO_PRESTACIONES = 4;

export function PlanCard({
  plan,
  destacado = false,
  activo = false,
  hrefDetalle,
  onCta,
  etiquetaCta = 'Ver plan',
}: PlanCardProps) {
  const incluidas = plan.prestaciones.filter((p) => p.estado === 'incluido').slice(0, MAXIMO_PRESTACIONES);

  return (
    <Card as="article" destacada={destacado || activo} className="flex flex-col gap-4">
      <div className="flex items-start justify-between gap-3">
        <div className="min-w-0">
          <h3 className="font-display text-xl text-ink-950">{plan.nombre}</h3>
          <p className="mt-1 text-sm text-ink-600">{plan.bajada}</p>
        </div>
        {activo ? <Badge tono="ok">Tu plan</Badge> : destacado ? <Badge tono="marca">Recomendado</Badge> : null}
      </div>

      <Money monto={plan.precio} periodo="por mes" tamano="lg" />

      <ul className="flex flex-col gap-2.5">
        {incluidas.map((prestacion) => (
          <li key={prestacion.label} className="flex items-center gap-2.5 text-sm text-ink-700">
            <Icon icono={Check} tono="ok" tamano="sm" />
            <span className="min-w-0 flex-1">{prestacion.label}</span>
            {prestacion.pendiente ? <Chip tono="warn">a confirmar</Chip> : null}
          </li>
        ))}
      </ul>

      <div className="mt-auto pt-1">
        {onCta ? (
          <Button ancho="full" onClick={() => onCta(plan)}>
            {etiquetaCta}
          </Button>
        ) : hrefDetalle ? (
          <Link to={hrefDetalle} className={clasesBoton({ ancho: 'full' })}>
            {etiquetaCta}
          </Link>
        ) : null}
      </div>
    </Card>
  );
}
```

```tsx
import type { LucideIcon } from 'lucide-react';
import { Check, Minus, X } from 'lucide-react';
import type { EstadoPrestacion, Plan } from '@/mock/planes';
import type { Tono } from '@/ui/tipos';
import { Icon } from '@/ui/Icon';
import { cn } from '@/lib/cn';

const GLIFO: Record<EstadoPrestacion, LucideIcon> = {
  incluido: Check,
  coseguro: Minus,
  'no-incluido': X,
};

const TONO: Record<EstadoPrestacion, Tono> = {
  incluido: 'ok',
  coseguro: 'warn',
  'no-incluido': 'neutro',
};

const ETIQUETA: Record<EstadoPrestacion, string> = {
  incluido: 'Incluido',
  coseguro: 'Con coseguro',
  'no-incluido': 'No incluido',
};

export interface PlanComparadorProps {
  actual: Plan;
  otros: Plan[];
}

/**
 * Una prestación que un plan NO nombra se muestra como `no-incluido`, no como
 * celda vacía: la ausencia no comunica, y acá se compara justamente eso.
 */
function estadoDe(plan: Plan, label: string): EstadoPrestacion {
  return plan.prestaciones.find((p) => p.label === label)?.estado ?? 'no-incluido';
}

export function PlanComparador({ actual, otros }: PlanComparadorProps) {
  const columnas = [actual, ...otros];
  const etiquetas = Array.from(new Set(columnas.flatMap((plan) => plan.prestaciones.map((p) => p.label))));

  return (
    <div className="overflow-x-auto rounded-card bg-white shadow-card ring-1 ring-ink-100">
      <table className="w-full min-w-[420px] border-collapse text-left">
        <caption className="sr-only">Comparación de prestaciones entre los planes</caption>
        <thead>
          <tr className="border-b border-ink-100">
            <th scope="col" className="px-4 py-3 text-sm font-medium text-ink-600">
              Prestación
            </th>
            {columnas.map((plan, indice) => (
              <th
                key={plan.slug}
                scope="col"
                className={cn(
                  'px-3 py-3 text-center text-sm font-medium whitespace-nowrap',
                  indice === 0 ? 'text-marca-700' : 'text-ink-600',
                )}
              >
                {plan.nombre}
              </th>
            ))}
          </tr>
        </thead>
        <tbody>
          {etiquetas.map((etiqueta) => (
            <tr key={etiqueta} className="border-b border-ink-100 last:border-0">
              <th scope="row" className="px-4 py-3 text-sm font-normal text-ink-800">
                {etiqueta}
              </th>
              {columnas.map((plan) => {
                const estado = estadoDe(plan, etiqueta);
                return (
                  <td key={plan.slug} className="px-3 py-3">
                    <div className="flex justify-center">
                      <Icon icono={GLIFO[estado]} tono={TONO[estado]} tamano="sm" etiqueta={ETIQUETA[estado]} />
                    </div>
                  </td>
                );
              })}
            </tr>
          ))}
        </tbody>
      </table>
    </div>

}
```

```ts
export interface DatosAlta {
  nombre: string;
  apellido: string;
  email: string;
  telefono: string;
}

export type ErroresAlta = Partial<Record<keyof DatosAlta, string>>;

export const DATOS_ALTA_VACIOS: DatosAlta = { nombre: '', apellido: '', email: '', telefono: '' };

/**
 * Validación deliberadamente laxa: un email "correcto" según la RFC igual puede
 * no existir. Lo único que se atrapa acá son los errores de tipeo evidentes.
 */
const EMAIL = /^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/;

const MINIMO_DIGITOS_TELEFONO = 8;

export function validarEmail(email: string): string | undefined {
  const valor = email.trim();
  if (valor === '') return 'Ingresá tu email';
  if (!EMAIL.test(valor)) return 'Revisá el email: falta el @ o el dominio';
  return undefined;
}

export function validarAlta(datos: DatosAlta): ErroresAlta {
  const errores: ErroresAlta = {};

  if (datos.nombre.trim().length < 2) errores.nombre = 'Ingresá tu nombre';
  if (datos.apellido.trim().length < 2) errores.apellido = 'Ingresá tu apellido';

  const email = validarEmail(datos.email);
  if (email !== undefined) errores.email = email;

  if (datos.telefono.replace(/\D/g, '').length < MINIMO_DIGITOS_TELEFONO) {
    errores.telefono = `Ingresá un teléfono de al menos ${MINIMO_DIGITOS_TELEFONO} dígitos`;
  }

  return errores;
}

export function hayErrores(errores: ErroresAlta): boolean {
  return Object.keys(errores).length > 0;
}
```

```ts
import { portalUrl } from '@/lib/urls';

export interface DatosUsuarioAlta {
  nombre: string;
  apellido: string;
  email: string;
  telefono: string;
}

export interface HandoffAlta {
  intent: 'alta';
  tipo: 'plan' | 'producto';
  id: string;
  usuario: DatosUsuarioAlta;
}

export interface HandoffLogin {
  intent: 'login';
  email: string;
}

export type Handoff = HandoffAlta | HandoffLogin;

/**
 * El intent vive en `sessionStorage` (no en `localStorage`) porque solo tiene
 * que sobrevivir el salto del popup a `/revisa-tu-mail`. El portal está en OTRO
 * origen, así que este storage nunca llega allá: el traspaso real va por la URL.
 */
export const CLAVE_HANDOFF = 'nexo3.alta';

export function construirUrlCallback(handoff: Handoff, base: string = portalUrl()): string {
  const parametros = new URLSearchParams();
  parametros.set('token', 'demo');
  parametros.set('intent', handoff.intent);

  if (handoff.intent === 'alta') {
    parametros.set('tipo', handoff.tipo);
    parametros.set('id', handoff.id);
    parametros.set('nombre', handoff.usuario.nombre);
    parametros.set('apellido', handoff.usuario.apellido);
    parametros.set('email', handoff.usuario.email);
    parametros.set('tel', handoff.usuario.telefono);
  } else {
    parametros.set('email', handoff.email);
  }

  return `${base.replace(/\/+$/, '')}/auth/callback?${parametros.toString()}`;
}

export function guardarHandoff(handoff: Handoff): void {
  try {
    sessionStorage.setItem(CLAVE_HANDOFF, JSON.stringify(handoff));
  } catch {
    // Storage bloqueado (modo privado de algunos navegadores): la maqueta sigue
    // funcionando, solo se pierde el resumen al recargar /revisa-tu-mail.
  }
}

export function leerHandoff(): Handoff | null {
  try {
    const crudo = sessionStorage.getItem(CLAVE_HANDOFF);
    if (crudo === null) return null;
    const parseado: unknown = JSON.parse(crudo);
    if (typeof parseado !== 'object' || parseado === null) return null;
    const intent = (parseado as { intent?: unknown }).intent;
    if (intent !== 'alta' && intent !== 'login') return null;
    return parseado as Handoff;
  } catch {
    return null;
  }
}

export function borrarHandoff(): void {
  try {
    sessionStorage.removeItem(CLAVE_HANDOFF);
  } catch {
    // Ver comentario de guardarHandoff.
  }
}
```

```tsx
import { Card } from '@/ui/Card';
import { Icon } from '@/ui/Icon';
import { clasesBoton } from '@/ui/Button';
import { EmptyState } from '@/ui/EmptyState';

export function RevisaTuMail() {
  // Se lee una sola vez al montar: el handoff no cambia mientras esta pantalla vive.
  const [handoff] = useState(() => leerHandoff());
  const [reenviado, setReenviado] = useState(false);

  if (handoff === null) {
    return (
      <div className="mx-auto max-w-[560px] px-4 py-16 lg:px-6">
        <EmptyState
          icono={MailQuestion}
          titulo="No hay una solicitud en curso"
          descripcion="Elegí un plan o un producto y completá el formulario para recibir tu enlace de acceso."
        >
          <Link to="/catalogo" className={clasesBoton({ variante: 'secundario' })}>
            Ver el catálogo
          </Link>
        </EmptyState>
      </div>
    );
  }

  const email = handoff.intent === 'alta' ? handoff.usuario.email : handoff.email;
  const urlCallback = construirUrlCallback(handoff);

  return (
    <div className="mx-auto max-w-[560px] px-4 py-12 text-center lg:px-6 lg:py-16">
      <div className="flex justify-center">
        <span className="inline-flex size-20 items-center justify-center rounded-pill bg-brand text-white">
          <MailCheck size={32} strokeWidth={1.5} aria-hidden="true" />
        </span>
      </div>

      <h1 className="mt-6 text-2xl text-ink-950">Revisá tu mail</h1>
      <p className="mt-3 text-base text-ink-600">
        Te enviamos un enlace de acceso a <span className="font-medium text-ink-900">{email}</span>. Abrilo
        desde el celular y entrás sin contraseña.
      </p>

      {/* Vista previa del mail: en la maqueta no hay servidor de correo, así que
          el "enlace mágico" se muestra acá y navega al portal por URL. */}
      <Card className="mt-8 text-left">
        <div className="flex items-center gap-3 border-b border-ink-100 pb-3">
          <Icon icono={MailCheck} tono="marca" tamano="sm" />
          <div className="min-w-0">
            <p className="text-sm font-medium text-ink-900">Nexo · Previnca Salud</p>
            <p className="truncate text-xs text-ink-500">Tu enlace de acceso</p>
          </div>
        </div>
        <p className="mt-4 text-sm text-ink-600">
          Hola{handoff.intent === 'alta' ? ` ${handoff.usuario.nombre}` : ''}, entrá con este enlace para
          continuar con tu contratación.
        </p>
        <a href={urlCallback} className={clasesBoton({ ancho: 'full', className: 'mt-4' })}>
          Abrir el mail (demo)
        </a>
        <p className="mt-3 text-xs text-ink-500">
          Vista previa de demostración. En producción este botón viaja dentro del correo.
        </p>
      </Card>

      <p className="mt-6 text-sm text-ink-600">
        ¿No te llegó?{' '}
        <button
          type="button"
          onClick={() => setReenviado(true)}
          className="font-medium text-marca-600 underline underline-offset-2 hover:text-marca-700"
        >
          Reenviar
        </button>
      </p>

      {reenviado ? (
        <p
          role="status"
          className="mx-auto mt-4 w-fit rounded-pill bg-ok-50 px-4 py-2 text-sm font-medium text-ok-700"
        >
          Te reenviamos el enlace.
        </p>
      ) : null}
    </div>
  );
}
```
